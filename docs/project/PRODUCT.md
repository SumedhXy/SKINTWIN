# PRODUCT.md - SkinTwin Product Truth

## Overview
**SkinTwin** is a local-first, privacy-focused photogrammetric skin telemetry and dermoscopic digital twin mobile & web application. It enables users to register, track, and analyze observable geometric and photometric changes in skin spots (moles, lesions, markings) over time with millimeter precision.

## Target Audience
- Individuals actively monitoring skin spots, moles, or lesions for baseline stability.
- Dermatology patients preparing for clinical visits or sharing telemetry with board-certified care networks.
- Privacy-conscious users requiring 100% on-device cryptographic data storage.

## Core Values & Product Truth
1. **Privacy First (On-Device Vault)**: All images, biometric markers, and telemetry parameters are encrypted and stored locally on-device.
2. **Clinical Precision & Trust**: Photogrammetric reticles, alignment quality scores (e.g., 98% parallel registration), and baseline vs. latest delta metrics (margin ±0.2mm).
3. **Non-Diagnostic Clarity**: Explicit, respectful messaging that SkinTwin tracks physical observations over time to assist healthcare providers without replacing medical diagnosis.
4. **Out-of-Distribution Craft**: Apple-inspired luxury UI—no decorative purple gradients, no generic cards, no AI slop. Deep contrast, purposeful typography, interactive split comparators.

## Key User Flows
- **Guided Capture**: Real-time camera viewfinder with alignment reticle, lighting check, and 98% parallel registration feedback.
- **My SkinTwins Library**: Searchable, filterable list of registered findings with status badges, millimeter delta metrics, and split preview thumbnails.
- **Photometric Comparison**: Interactive side-by-side & live drag slider view comparing baseline and latest captures.
- **Find Care Network**: Provider directory for booking consultations and securely sharing vault telemetry.
